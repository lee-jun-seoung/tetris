# STACK — 테트리스

별도의 설치 과정 없이 브라우저에서 바로 즐길 수 있는 클래식 테트리스입니다.

## 시작하기

`index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다. Google Fonts 연결을 사용할 수 없는 환경에서는 기본 글꼴로 표시됩니다.

## 조작법

| 키 | 동작 |
| --- | --- |
| ← / → | 좌우 이동 |
| ↓ | 한 칸 내리기 |
| ↑ 또는 X | 시계 방향 회전 |
| Z | 반시계 방향 회전 |
| Space | 즉시 내리기 |
| C | 블록 보관 / 교체 |
| P 또는 Esc | 일시정지 |

## 모바일 조작

화면 아래의 버튼으로 좌우 이동, 회전, 한 칸 내리기, 즉시 내리기, 보관, 일시정지를 할 수 있습니다. 좌우 이동과 아래 버튼은 길게 누르면 반복 입력됩니다. 게임판을 탭하면 회전하고, 좌우로 밀면 이동하며, 아래로 밀면 블록이 즉시 내려갑니다.

점수와 최고 점수는 브라우저의 `localStorage`에 저장됩니다. 10줄을 지울 때마다 레벨이 올라가고 낙하 속도가 빨라집니다.
